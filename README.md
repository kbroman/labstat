## Installation

Install the package from [r
universe](https://kbroman.r-universe.dev/labstat):

```r
install.packages("labstat", repos="https://kbroman.r-universe.dev")
```

Alternatively, use the [remotes](https://remotes.r-lib.org) package to
install it from [GitHub](https://github.com/kbroman/labstat):

```r
install.packages("remotes")
library(remotes)
install_github("kbroman/labstat")
```
